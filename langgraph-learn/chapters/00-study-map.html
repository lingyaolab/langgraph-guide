00 · 学习地图：怎么用本站 + 前置知识

这是一套按「先跑通、再理解、最后避坑」重排的 LangGraph 教程。你不需要先读完官方文档， 但需要会写 Python、见过 async/await，并且愿意先照抄再追问为什么。

为什么要再造一个文档站

官方文档按 API 组织，适合查；学习时真正卡住你的通常是三件事： 这段代码和上一段是什么关系、状态到底在哪一步变了、出错时该看哪一层。 这个站按工程落地顺序重写，每个结论都尽量标回 langgraph-1.2.20 的源码。

三条学习主线：同一章读三遍

① 跟做线

  • 先看「最小可跑」，照着敲，不追求看懂
  • 每段代码都能独立运行，不依赖隐藏片段

② 理解线

  • 看「逐行解读 / 端到端」，把一次执行拆成建图、调度、合并、持久化
  • 遇到不懂的 API，先看它属于哪一层，再看签名

③ 避坑线

  • 看「陷阱与窍门」：你会看到 X → 因为 Y → 改成 Z
  • 把报错原文和触发条件记进自己的排障笔记

没有 API Key，能学到哪一步

00A、01、02、03 的前半、05、06、09、10、15 都可以用假模型或纯函数跑通； 需要真实模型的主要是 03 的路由实验、04、07、08、11–14、17。把「不需要 key」的章节先做完， 再决定要不要申请额度。

每一章的固定结构与图例

  • 读完你能做到：这一章的验收标准。
  • 先说为什么：不先讲 API，先讲它解决什么问题。
  • 最小可跑：能独立运行的最小代码。
  • 逐行解读 / 端到端：关键行与一次执行的完整链路。
  • 陷阱与窍门：按「现象 → 原因 → 改法」写。
  • 自检三问 / 动手练习：做完再进入下一章。
