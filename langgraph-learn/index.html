把 LangGraph 1.2.20 学到「能自己搭一张可恢复的图」

这不是官方文档的搬运，而是一套按工程落地顺序重排、每个结论都能回源码验证的教程。 默认模型是 DeepSeek，示例全部是可运行的 Python。每一章都有最小可跑、一次执行的完整链路、 以及「你会撞到什么错」。

我该从哪儿开始

  1. 先花 12 分钟读「学习地图」
    它会告诉你三条主线怎么用、章节为什么是这个顺序、以及没有 API Key 能学到哪一步。
    → 00 学习地图
  2. 跑通第一张图（约 30 分钟）
    → 01 环境与第一个图：一个 StateGraph、两个节点、一条边，compile().invoke() 看到 state 变化。
  3. 理解状态与路由（约 80 分钟）
    → 02 State 与 Reducer、 03 条件路由：先写对状态更新语义，再让图自己决定下一步。
如果你只想最快验证「这套东西能不能跑」

直接看 01 章的最小可跑：一个 Python 文件、一个 StateGraph、一次 invoke，不需要 API Key。

三条学习主线

① 跟做线：照抄能跑

  • 每章「最小可跑」都是完整代码，不依赖前文的隐藏片段
  • 出现过的 API 都能在附录 C 的速查表里查到
  • 目标是「先跑起来」，不追求先看懂

② 理解线：知道它在干什么

  • 每章「端到端」把一次执行拆成建图、调度、状态合并、持久化四段
  • 关键机制给分层图：谁调用谁、状态在哪一步变化、失败在哪一层

③ 避坑线：出错时知道看哪儿

  • 每章「陷阱与窍门」按「你会看到 X → 因为 Y → 改成 Z」写
  • 重点标出「静态图看起来对、运行时才炸」的边界

本站内容严格对应 LangGraph 1.2.20，写作时逐条回源核对，来源只有三类：

类型 路径 用来确认什么

已知边界
  • LangGraph 1.x 与 0.x 的 API 有破坏性变化；网上大量教程仍在使用 0.2/0.3 的写法，迁移前先看附录 D 与 18 章。
  • 官方文档覆盖 API 参考；本站不重复翻译，只补「学习顺序、可运行工程、版本差异与踩坑」。
